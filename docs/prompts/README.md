# Reusable Prompts

This directory stores reusable prompts for AI tools (ChatGPT, Claude, Codex) used in development.

## Naming Convention

```
<phase>-<tool>-<task>.md
```

Examples:
- `phase1-codex-player-movement.md`
- `phase2-codex-combat-system.md`
- `phase3-chatgpt-networking-design.md`

## Guidelines

- Each prompt should be self-contained
- Include context from the blueprint and architecture docs
- Specify which files/folders the output should target
- Reference the relevant ADRs for architecture constraints
- Include acceptance criteria
